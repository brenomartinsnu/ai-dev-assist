# sindarin

**OPC for in-app wallet provisioning** — GitHub description: service responsible for building **OPC** (Opaque Payment Card data / provisioning payloads) for **wallets in-app provisioning** flows.

## Repository

- https://github.com/nubank/sindarin

## ISA

- https://backoffice.ist.nubank.world/isa/#/services/sindarin/overview

## Role in card creation ecosystem

- Downstream of having a live card + tokenization path: helps put the card into **digital wallets** from the app. Works in the same problem space as **piata** / **lost-boy** / **saturn** but at the **provisioning payload** layer.
